# qr-code-generator

A simple static page to generate QR codes from any text or URL.

## Usage

Open `/home/runner/work/qr-code-generator/qr-code-generator/index.html` in a browser.

1. Enter a URL or text.
2. Click **Create QR code**.
3. Choose the download format (**PNG** or **PDF**).
4. Click **Download**.
